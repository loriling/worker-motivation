# 打工人鼓励器

一个根据月薪和工作时间实时计算当天收入的静态网页工具，让每一秒的工作都有迹可循。

## 功能

- 根据月薪、工作日和上下班时间换算收入
- 自动判断当前是否处于工作时间
- 实时显示今日收入和工作进度
- 展示每小时、每分钟和每秒收入
- 使用 `localStorage` 在本机保存设置
- 支持安装为 PWA，并可在首次加载后离线使用
- 支持桌面端和移动端

## 本地使用

直接使用浏览器打开 `index.html`，或在项目目录启动任意静态文件服务器：

```bash
python -m http.server 4173
```

然后访问 `http://127.0.0.1:4173/`。

PWA 安装与离线能力需要通过 `localhost` 或 HTTPS 访问，直接双击打开 HTML 时仍可使用核心计时功能，但无法注册 Service Worker。

## 隐私

月薪和工作时间仅保存在当前浏览器的本地存储中，不会上传到服务器。

## 技术栈

原生 HTML、CSS 和 JavaScript，无第三方运行时依赖。
